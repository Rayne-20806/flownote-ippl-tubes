## 📌 Tentang Proyek

**FlowNote** adalah platform *note-taking* dan manajemen tugas berbasis web online yang dirancang untuk membantu mahasiswa serta dosen dalam mencatat, mengorganisir ide, dan mengelola agenda secara terstruktur.

Aplikasi ini dikembangkan untuk memenuhi Tugas Besar mata kuliah **Implementasi Perancangan Perangkat Lunak (IPPL)** di Universitas Telkom. Selain fitur pencatatan utama (*Core Notebook*), FlowNote dilengkapi dengan modul **Digital Store & Point of Sale (PoS)** untuk pembelian template *planner* digital serta paket langganan fitur premium.
